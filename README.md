# ExplicaFé

Projeto audiovisual sobre toda a Bíblia católica, desenvolvido em colaboração
por Codex, Claude Code e Google Antigravity.

- [Decisões](docs/decisions/README.md)
- [Histórico de entregas](docs/handoffs/README.md)

Os testes usam a biblioteca padrão do Python 3 e rodam no GitHub Actions.
A [skill de integração](docs/skills/integracao.md) descreve como testar,
publicar a prévia e conferir o endereço fixo. O fluxo pode ser operado pelo
navegador ou pelo ambiente da IA.
