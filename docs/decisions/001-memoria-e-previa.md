# 001 · GitHub como memória compartilhada

**Data** · 24/11/2026

**Decisão** · Adotar o fluxo colaborativo do King Rico no ExplicaFé.
Entradas específicas encaminham para um protocolo comum. O estado fica no
HANDOFF e no TODO, e o histórico fica versionado no GitHub. GitHub Pages
serve a prévia estática a partir de uma branch compartilhada.

**Motivo** · Qualquer ferramenta pode retomar pelo mesmo commit, ler o mesmo
contexto e colaborar pelo mesmo fluxo. Uma página estática permite verificar
a publicação sem depender de infraestrutura adicional.

**Consequências** · A disponibilidade da prévia depende do plano, da
visibilidade do repositório e das permissões do GitHub. A publicação oficial
será definida quando houver escopo aprovado.
