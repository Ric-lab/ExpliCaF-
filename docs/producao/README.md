# Pesquisa técnica de produção audiovisual

**Data** · 24/11/2026. **Estado** · recomendação para aprovação.

Recomendo um **projeto de vídeo com linha do tempo versionada no GitHub**,
voz sintetizada em CPU com Kokoro ONNX e finalização com FFmpeg. O primeiro
piloto deve testar o HyperFrames como camada visual HTML/CSS/SVG. Se o
navegador não for viável no executor escolhido, o caminho comprovado com
SVG e FFmpeg sustenta um piloto mais simples. A escolha do renderizador
visual fica aberta até comparar o resultado e o custo de execução.

A proposta evita APIs pagas, instalação no computador do responsável e
tarefas manuais por cena. Os agentes editam a mesma árvore de arquivos e
executam o mesmo comando na nuvem. A intervenção humana se concentra na
aprovação editorial, na escuta da voz e na autorização de publicação.
